SECOND BRAIN OS
Rewrite Minds · v3.3.0

------------------------------------------------------------
WHAT THIS IS
------------------------------------------------------------

One place for everything that enters your head — tasks,
projects, notes, journal and a weekly review.

It is a single folder of files that runs in your browser.
There is no account, no sign-up, no subscription and no
server. Nothing you type is ever uploaded anywhere.

------------------------------------------------------------
HOW TO OPEN IT
------------------------------------------------------------

1. Unzip the download. You get one folder called
   "Second Brain OS".
2. Move that whole folder somewhere permanent
   (Documents is fine — do not leave it in Downloads).
3. Open the folder and double-click  index.html
4. It opens in your browser and works immediately.

Runs in any current browser: Chrome, Edge, Firefox, Brave
and Safari. (Tested in Chrome and Edge.)

IMPORTANT: keep the folder intact. index.html needs the
assets folder that sits beside it. Do not move index.html
on its own, and do not rename the assets folder.

------------------------------------------------------------
FIRST LAUNCH
------------------------------------------------------------

The first time you open it, a short title animation plays,
then four setup screens take about forty seconds.

The title screen renders a chrome brain in 3D. That is the
only part of the app that uses WebGL; if your browser has it
switched off, you get a still image instead and everything
else behaves identically.

The animation plays every time you open the app. To turn it
off, or to replay it on demand, go to Settings -> Appearance
-> Launch animation.

The four setup screens appear only once, on the very first
launch. To see them again - or to show someone else - use
Settings -> Appearance -> First-run tour -> Take the tour.
Replaying the tour never changes your data.

No internet connection is needed at any point when you run
it from this folder. The three files that draw the 3D brain
are included with the download, not fetched from a server.

------------------------------------------------------------
HOW TO INSTALL IT AS AN APP  (optional)
------------------------------------------------------------

Installing to your home screen requires the files to be
served over https, so this only works from the hosted link
supplied with your purchase — not from the unzipped folder.

Chrome / Edge (desktop): open the hosted link, then click
the install icon in the address bar.
Android Chrome: open the hosted link -> menu -> Add to Home screen.
iPhone Safari: open the hosted link -> Share -> Add to Home Screen.

Once installed it still works with no internet.

------------------------------------------------------------
YOUR DATA
------------------------------------------------------------

Everything is stored in your browser's local storage on the
device you are using. That means:

  · It does not sync between devices by itself.
  · Clearing your browser data deletes it.
  · Incognito / private windows forget it when closed.

So use Settings -> Export backup regularly. That produces one
.json file containing everything. On a new device, open the
app and use Settings -> Import backup.

Recommended habit: export at the end of every weekly review.

------------------------------------------------------------
THE FOUR RULES
------------------------------------------------------------

1. Capture everything in the bar at the top.
2. Empty the inbox every morning — task, note, or delete.
3. Work from Today, never from the inbox.
4. Review every seven days. The app will remind you.

The software is not the system. The four rules are.

  N              new task
  C              focus the capture bar
  /              search
  Esc            close / cancel
  ?              shortcuts

------------------------------------------------------------
IF SOMETHING BREAKS
------------------------------------------------------------

Almost every problem is one of these two things:

  · You moved index.html away from the assets folder.
  · You opened it in a private/incognito window, so the
    browser refuses to save anything.

If a page looks blank, press Ctrl+Shift+R (Cmd+Shift+R on Mac)
to force a reload.
